# 异录图片资源

图片按角色或用途命名。角色目录来自 https://deft-lily-7a3c8b.netlify.app/ 。

- 角色立绘索引：`角色立绘索引.json`（84 位角色）。
- 图片名称索引：`图片名称索引.json`，原地址及哈希见 `manifest.json`。
- 新增缘叶、渊、苏青立绘；共349张取回图片，另有地图纹理/环境/模型。
- 老版固定提交地址继续可用，新版使用本次命名后的文件。
